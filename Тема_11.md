## Лабораторная работа №2

### Класс итератор с гибкой настройкой и удобными применением

```python
class CountDown:
    def __init__(self,start):
        self.count = start + 1

    def __iter__(self):
        return self

    def __next__(self):
        self.count -= 1
        if self.count < 0:
            raise StopIteration
        return self.count

if __name__=="__main__":
    counter = CountDown(5)
    for i in counter:
        print(i)
```

### Результат.

![Лаб2]()

## Выводы

В данном коде создаётся класс-итератор, который в конструкторе принимает количество итераций. Функция iter возвращает значение итератора, а в функции next осуществляет уменьшение шагов на один и возвращение шага. Если количество шагов меньше нуля, то вызывается исключение, которое останавливает итерацию.
В точке входа осуществляется создание объекта-итератора с номером начального шага и вывод каждого элемента итерации.

Далее помимо того, что генератор списка можно вызывать многократно, генераторные выражения можно вызвать только один раз.

## Лабораторная работа №5

### Такой же счетчик, как и в первом задании, только это генератор и использует yield

```python
def countdown(count):
    while count>=0:
        yield count
        count-=1

if __name__=="__main__":
    counter = countdown(5)
    for i in counter:
        print(i)
```

### Результат.

![Лаб5]()

## Выводы

В данном коде создаётся функция-генератор, которая уменьшает счётчик на 1, как во втором упражнении. В функции countdown есть цикл while, который выполняется до тех пор пока счётчик count больше нуля.
Функция yield возвращает объект-генератор счётчика и уменьшает count на единицу. В точке входа осуществляется вызов функции countdown и вывод всех сгенерированных элементов при помощи цикла for.

## Самостоятельная работа №1

### Вас никак не могут оставить числа Фибоначчи, очень уж они вас заинтересовали. Изучив новые возможности Python вы решили реализовать программу, которая считает числа Фибоначчи при помощи итераторов. Расчет начинается с чисел 1 и 1. Создайте функцию fib(n), генерирующую n чисел Фибоначчи с минимальными затратами ресурсов. Для реализации этой функции потребуется обратиться к инструкции yield (Она не сохраняет в оперативной памяти огромную последовательность, а дает возможность “доставать” промежуточные результаты по одному). Результатом решения задачи будет листинг кода и вывод в консоль с числом Фибоначчи от 200.

```python
def fib(n):
    fibA,fibB=1,1 #начальные числа 1 и 1, как указано в задаче
    for i in range(n):
        fibA, fibB = fibB, fibB + fibA
        yield fibB
    print("\n200-ое число Фибоначчи =", fibB)


if __name__=="__main__":
    Fibonacci = fib(200)
    for i in Fibonacci:
        print(i, end = " ")

```

## Выводы

В данном коде создаётся функция-генератор, которая генерирует последовательность чисел Фибоначчи. Начальные числа заданы по условию 1 и 1. В цикле for осуществляется подсчёт нового числа на основе предыдущих и возращение объекта результата подсчёта fibB при помощи yield.
Также в консоль выводится последнее подсчитанное двухсотое число. В точке входа осуществляется вызов функции fib(200) и итерация вывода на консоль.

## Самостоятельная работа №2

### К коду предыдущей задачи добавьте запоминание каждого числа Фибоначчи в файл “fib.txt”, при этом каждое число должно находиться на отдельной строчке. Результатом выполнения задачи будет листинг кода и скриншот получившегося файла

```python
def fib(n):
    fibA,fibB=1,1 #начальные числа 1 и 1, как указано в задаче
    file = open("fib.txt", "w")
    for i in range(n):
        fibA, fibB = fibB, fibB + fibA
        file.write(str(fibB) + "\n")
        yield fibB
    file.close()
    print("\n200-ое число Фибоначчи =", fibB)


if __name__=="__main__":
    Fibonacci = fib(200)
    for i in Fibonacci:
        print(i, end = " ")
```

## Общие выводы по теме

Благодаря данной теме были изучены генераторы и итераторы в Python. А также итераторы как собственные классы с **iter** и **next**, то что по своей природе все файлы - итераторы, и метод iter возвращает сам итератор, а next - следующий элемент коллекции.
Произошло понимание различий между генераторами списков и генераторными выражениями. И то, что если функция содержит yield - то, она сразу становится генератором. Yield - возвращает объект генератора. Когда функция с yield вызывается, она возвращает объект-генератор, а не результат выполнения функции.
Генераторы обрабатываются с помощью циклов for, функций next(), их можнопередавать в функции, которые ожидают итераторы, и так далее. При каждой итерации генератор возвращает следующее значение по одному элементу за раз. Генераторы имеют ленивую итерацию и выполняются ровно один раз. Вызвать больше одного раза их нельзя (выполняются по мере необходимости).
