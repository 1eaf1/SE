### Вам дали важное задание, написать продавцу мороженого программу, которая будет писать добавили ли топпинг в мороженое и цену после возможного изменения. Для этого вам нужно написать класс, в котором будет определяться изменили ли состав мороженого или нет. В этом классе реализуйте метод, выводящий на печать «Мороженое с {ТОППИНГ}» в случае наличия добавки, а иначе отобразится следующая фраза: «Обычное мороженое». При этом программа должна воспринимать как топпинг только атрибуты типа string.

```python
class IceCream:
    def __init__(self,ingredient=None):
        if isinstance(ingredient,str):
            self.ingredient = ingredient
        else:
            self.ingredient=None

    def composition(self):
        if self.ingredient:
            print(f"Мороженое с {self.ingredient}")
        else:
            print("Обычное мороженое")

icecream = IceCream()
icecream.composition()
icecream = IceCream("Шоколадом")
icecream.composition()
icecream=IceCream()
icecream.composition()
icecream=IceCream("Ванилью")
icecream.composition()
```

## Лабораторная работа №5
### На разных языках здороваются по-разному, но суть остается одинаковой, люди друг с другом здороваются. Давайте вместе с вами реализуем программу с полиморфизмом, которая будет описывать всю суть первого предложения задачи. Для этого мы можем выбрать два языка, например, русский и английский и написать для них отдельные классы, в которых будет в виде атрибута слово, которым здороваются на этих языках. А также напишем функцию, которая будет выводить информацию о том, как на этих языках здороваются. Заметьте, что для решения поставленной задачи мы использовали декоратор @staticmethod, поскольку нам не нужны обязательные параметры-ссылки вроде self.

```python
class Russian:
    @staticmethod
    def greetings():
        print("Привет!")

class English:
    @staticmethod
    def greetings():
        print("Hello!")

def greet(language):
    language.greetings()

ivan = Russian()
john = English()
greet(ivan)
greet(john)
```

За пределами классов создаётся функция, которая принимает аргумент language и обращается к методу greetings переданного аргумента. Таким образом, при передаче любого из объектов двух классов в функцию greet будет вызываться метод greetings переданного объекта.

```python
class Tomato:
    states = {1:"Отсутствует",2:"Цветение",3:"Зелёный",4:"Красный"}
    def __init__(self,index=1):
        """Эти два свойства являются защищёнными атрибутами - т.е. атрибутами
            доступными только внутри самого класса и его дочерних классах"""
        self._index = index
        self._state = Tomato.states.get(1)

    def grow(self): # Перевод томата на следующую стадию созревания
        if self._index<4:
            self._index+=1

    def is_ripe(self): # Проверка спелости томата
        if self._index==4:
            print("Томат созрел")
            return self._index
        else:
            print(f"Томат в стадии: {Tomato.states.get(self._index)}")

class TomatoBush:
    def __init__(self,count_of_tomatoes):
        self.tomatoes = []
        for i in range(count_of_tomatoes):
            tomato = Tomato()
            self.tomatoes.append(tomato)

    def grow_all(self): # Перевод всех объектов Tomato на следующий этап созревания
        for self.tomato in self.tomatoes:
            self.tomato.grow()

    def all_are_ripe(self): #Проверка всех томатов на спелость
        counter = 0
        for self.tomato in self.tomatoes:
            if self.tomato.is_ripe():
                counter+=1
                if counter == len(self.tomatoes):
                    return True

    def give_away_all(self): #Очищение списка томатов после сбора урожая
        self.tomatoes.clear()

class Gardener:
    def __init__(self,name,bush):
        """Свойство name является публичным свойством, а свойство _plant является защищённым свойством"""
        self.name = name
        if isinstance(bush,TomatoBush):
            self._plant = bush
        else:
            print("Передан не куст, перезапустите программу и передайте куст")

    def work(self): # Метод позволяет растению становиться более зрелым
        self._plant.grow_all()
        print("Ухаживание за кустом...")

    def harvest(self): # Метод сбора урожая
        if self._plant.all_are_ripe() is True:
            print("Урожай собран")
            self._plant.give_away_all()
        else:
            print("Урожай ещё не созрел!")

    @staticmethod
    def knowledge_base(): # Справка по садоводству
        print("Справка по садоводству:\n1) Посадить куст томатов.\n2) Назначить садовника на куст\n3) Ухаживание за кустом.\n4) Сбор урожая\n")

if __name__=="__main__":
    Gardener.knowledge_base() # Вызов справки
    tomatoBush = TomatoBush(3) #Создание куста с помидорами
    gardener = Gardener("Иннокентий",tomatoBush) #Назначение садовника на куст
    gardener.work()
    gardener.harvest() #Попытка сбора урожая
    gardener.work() #Продолжение ухаживания за кустом
    gardener.work()
    gardener.harvest() #Окончательный сбор урожая
```
