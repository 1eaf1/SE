## Лабораторная работа №1
### Допустим, что вы решили оригинально и немного странно познакомится с человеком. Для этого у вас должен быть написан свой класс на Python, который будет проверять угадал ваше имя человек или нет. Для этого создайте класс, указав в свойствах только имя. Дальше создайте функцию __init__(), а в ней сделайте проверку на то угадал человек ваше имя или нет. Также можете проверить что будет, если в этой функции указав атрибут, который не указан в вашем классе, например, попробуйте вызвать фамилию.

```python
class GuessTheName:
    __slots__ = ['name']

    def __init__(self,name):
        if name == "Евгений":
            self.name = f"Да,я {name}"
        else:
            self.name = f"Я не {name}, а Евгений"

person1 = GuessTheName("Евгений")
person2 = GuessTheName("Алексей")
print(person1.name)
print(person2.name)

person2.surname = "Петров"

```

## Выводы
В данном коде в классе GuessTheName указан атрибут __slots__, который позволяет сделать ограниченным количество свойств в классе. В данном случае класс может иметь всего одно свойство name. При добавлении новго свойства, такого как surname или любого другого - консоль выведет ошибку. В данном классе в конструкторе осуществляется проверка ответа имени, если имя правильно то выводится подтверждение догадки, если нет, то выводится сообщение что имя не то, и выводится настоящее имя. Далее создаются два объекта класса GuessTheName и им в качестве аргументов передаются имена. Далее в консоли вызывается и выводится на консоль аргумент name каждого объекта с определённым результатом, осуществлённым в конструкторе. Далее второму объекту класса person2 осуществляется попытка создать новое свойство surname, однако это безуспешно из-за наличия __slots__ и в консоль выводится ошибка.
