## Лабораторная работа №1
### Наверняка вы думаете, что декораторы – это какая-то бесполезная вещь, которая вам никогда не пригодится, но тут вдруг на паре по математике преподаватель просит всех посчитать число Фибоначчи для 100. Кто-то будет считать вручную (так точно не нужно), кто-то посчитает на калькуляторе, а кто-то подумает, что он самый крутой и напишет рекурсивную программу на Python и немного огорчится, потому что данная программа будет достаточно долго считаться, если ее просто так запускать. Но именно тут к вам на помощь приходят декораторы, например @lru_cache (он предназначен для решения задач динамическим программированием, если простыми словами, то этот декоратор запоминает промежуточные результаты и при рекурсивном вызове функции программа не будет считать одни и те же значения, а просто “возьмёт их из этого декоратора”). Вам нужно написать программу, которая будет считать числа Фибоначчи для 100 и запустить ее без этого декоратора и с ним, посмотреть на разницу во времени решения поставленной задачи.

```python
from functools import lru_cache

@lru_cache(None)
def fibonacci(n):
    if n==0:
        return 0
    elif n==1:
        return 1
    return fibonacci(n-1) + fibonacci(n-2)

if __name__=="__main__":
    print(fibonacci(100))
```

from time import time

def decorator(func):
    def wrapper():
        start_time = time()
        func()
        end_time = time()
        result_time = end_time - start_time
        print(f"\nЧисла Фибоначчи посчитаны за: {result_time} секунд")
        return result_time
    return wrapper

@decorator

```python
class Binary: 
    """Создание класса-декоратора и функции инициализации декоратора и вызова декоратора. В функции __call__
    осуществляется принятие аргументов и выполнение переданных в декоратор функций - вывод результатов выполнения
    функций в десятичном и двоичном представлении"""
    def __init__(self, func):
        self.func = func

    def __call__(self, *args, **kwargs):
        result = self.func(*args)
        print(f"{self.func.__name__} в десятичной системе: {result}")
        result = bin(result)
        print(f'В двоичной: {result}')

@Binary
def SummarizeOfNumbers(*args):
    """Данная функция осуществляет сложение любого количества чисел, переданных пользователем с консоли"""
    result = 0
    for i in range(len(args)):
        result = result + args[i]
    return result
@Binary
def MultiplyOfNumbers(*args):
    """Данная функция осуществляет умножение всех чисел, переданных пользователем с консоли"""
    result = 1
    for i in range(len(args)):
        result *= args[i]
    return result

if __name__=="__main__": #Точка входа
    SummarizeOfNumbers(5,9,2)
    MultiplyOfNumbers(10,5,-1,4)

В блоке try осуществляется проверка заглавной буквы в имени или фамилии и является ли первый символ буквой. Если условие выполняется, то на экран выводится имя/фамилия. В блоке except осуществляется обработка исключения и проверкая не является ли первый символ буквой. Если условие выполняется, то выводится сообщение о том, что фамилия не должна содержать цифр и спецсимволы. В точке входа осуществляется вызов функций.
